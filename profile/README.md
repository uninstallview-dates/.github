# UninstallView - Remove a Program You Installed

At a glance:
- Installed names on this PC
- The uninstaller that program registered
- One removal, then a check that you can still sign in and update
- No sweep of Windows itself

## The Registered Uninstaller

UninstallView shows software Windows knows how to remove. You select a name you recognize, start that entry's uninstall, and follow its own prompts. That is safer than deleting the program's folder. The folder delete can leave the entry, or it can remove files another program shares.

Sort by name and find the tool you meant. Dates help you see what arrived recently. If you do not remember installing it, leave it until you know what it is. A security update or a driver is not a candidate because the name looks long.

## One Name

Remove one program. Reboot if it asks. Open something you need: the browser, your documents, Windows Update. If those still work, you can consider another name another day. A batch of quiet uninstalls is how a codec or a runtime disappears and a different app stops starting. Do not queue removals you have not read.

Leftover data in your user folder may be settings you wanted to keep. Look before you delete a directory the uninstaller left behind. If the name matches the program and you do not need the settings, you may remove that folder. If the path is Windows or Program Files and you are unsure, leave it.

## Not A Cleaner Of The System

This is not a tune-up and not a license to delete services. Defender, updates, and drivers stay. If a guide says to uninstall a long list of Windows packages, do not follow it from this window. The goal is a program you added, such as a trial you finished, removed by its own uninstall.

## After The Reboot

Some uninstallers finish only after restart. Reboot before you judge the result. Then look at the list again. If the name remains, the uninstall did not complete. Run it once more or use the vendor's own remover. Do not delete the program directory as the first retry.

## Shared PC

On a computer other people use, uninstall only what you installed for yourself or what you were asked to remove. A quiet flag can remove software without a prompt the next person would have wanted to see. Prefer the normal uninstall when the PC is shared. Tell the other user if a shared tool is going away.

## The Publisher Column

The publisher next to the name is part of the decision. If it does not match the tool you remember installing, do not uninstall yet. A familiar publisher and a familiar name, one at a time, is the row you can remove.

## Player Profile

UninstallView fits removing a program you added and no longer use. It does not fit deleting system components, a batch of quiet removals you did not read, or uninstalling another person's software on a shared PC without asking.

## Help Desk

The name remains after uninstall? Reboot and run that entry once more. Do not delete Program Files first.
Something else stopped working? You removed a runtime it needed. Reinstall that runtime from the vendor you already use.
You do not recognize a name? Leave it.
A folder leftover looks like Windows? Do not delete it.
The PC is shared? Use the normal prompts and tell the other person.

## Reader Notes

One familiar name is the right first removal. The registered uninstaller knows its files better than a manual delete. The test afterward tells you the PC still does what you need.

Quiet and batch options are for a list you have already read, not for a first afternoon. Dates help you see what you installed last week. They do not mark system updates as junk.

Leave security tools and drivers alone. A shorter installed list is not the goal. A program you chose to remove, gone, with everything else still starting, is the goal.
